# Mapa de archivos

## Si el profe pide agregar una palabra reservada

Tocar:

- `MiLenguaje.g4`

## Si pide agregar una construccion global

Tocar:

- `MiLenguaje.g4`

Conectarla en:

- `elemento`

## Si pide agregar una sentencia

Tocar:

- `MiLenguaje.g4`

Conectarla en:

- `sentencia`

## Si pide agregar una expresion u operador

Tocar:

- `MiLenguaje.g4`
- `AnalizadorSemantico.java`
- `GeneradorCodigo.java`

## Si pide agregar un tipo nuevo

Tocar:

- `MiLenguaje.g4`
- `AnalizadorSemantico.java`

## Si pide que algo aparezca en la tabla

Tocar:

- `AnalizadorSemantico.java`

Y si queres que salga prolijo:

- `Simbolo.java`
- `TablaSimbolos.java`

## Si pide validar algo semanticamente

Tocar:

- `AnalizadorSemantico.java`

## Si pide nueva salida de codigo intermedio

Tocar:

- `GeneradorCodigo.java`

## Si pide una optimizacion nueva

Tocar:

- `optimizaciones/NuevaOptimizacion.java`
- `Optimizador.java`

## Si pide una regex nueva

Tocar:

- parte lexica de `MiLenguaje.g4`

## Si pide nuevos warnings

Tocar:

- `AnalizadorSemantico.java`

## Si pide nueva columna en la tabla

Tocar:

- `Simbolo.java`
- `TablaSimbolos.java`
